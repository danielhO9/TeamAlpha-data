# 재무 단위와 외화 환산 수정 기록

2026년 10월 1일 점검에서 DART API 재무 단위 오류와 Gold의 통화 미환산을 확인했다. 이 기록은 실제 RDS에 반영한 원천 데이터 수정과, 아직 재생성하지 않은 Gold 및 전략 결과를 구분한다. 순위 변환이나 극값 캡은 추가하지 않았다.

## 반영 상태

| 대상 | 상태 |
| --- | --- |
| RDS 표준 재무 fundamental | 원본 공시와 대조한 13개 공시의 272행 수정 완료 |
| RDS 환율 fx_rate_daily | 2014년 1월 1일부터 2026년 9월 30일까지 5개 통화 16629행 적재 완료 |
| 원본 Bronze와 fundamental_statement_line | 변경하지 않음 원천 API 오류까지 그대로 보존 |
| 수집과 Gold 계산 코드 | 로컬 수정과 테스트 완료 |
| 운영 ECS 이미지 | 아직 배포하지 않음 |
| 저장된 gold.factor_value | 46개 새 CANDIDATE 버전에 전체 재생성 진행 중, 기존 APPROVED 49개 유지 |
| 전략 캐시와 대시보드 | 수정 Gold의 4개 조합 실행 준비 완료, 공개 사이트는 아직 기존 결과 |
| RDS 저장공간 | 사용자 승인으로 150GB → 250GB 확장 반영 완료 |

따라서 기존 Gold나 대시보드를 수정 후 결과로 해석하면 안 된다. 운영 반영 시에는 새 Gold 구현 버전을 등록하고 전체 학습 이력을 재생성한 다음 승인 버전을 전환해야 한다. 비어 있거나 일부 기간만 적재된 버전을 먼저 승인하지 않는다. 기존 구현의 해시만 덮어쓰지 않는다.

## 확인한 재무 오류

소프트센, 소노스퀘어, 에이아이비트, 아즈텍WB, 3S, 유아이디, 동성케미컬, 코오롱머티리얼, 이큐셀, 다원넥스뷰, 삼성스팩7호, 하나34호스팩의 특정 공시는 API 금액이 원본 문서보다 백만 배 컸다. SK네트웍스의 2017년 3분기 공시는 반대로 백만 원 표시를 원으로 취급해 백만 배 작았다.

수정은 회사 전체가 아니라 정확한 공시 접수번호와 연결 또는 별도 범위로 제한했다. 자산총계 원값을 확인하고 같은 접수번호의 DART 원문에서 각 표준 지표의 금액과 부호를 대조했다. SK네트웍스는 문서의 백만 원 단위를 적용했다. 값이 크다는 이유만으로 나누거나 잘라내지 않았다.

공시 목록과 원래 자산총계는 `pipeline/silver/reviewed_financial_units.py`에 있다. 원본 ZIP은 `data/financials/unit_evidence/rcept=<접수번호>/document.zip`에 저장했다. RDS `financial_unit_repair`는 변경 전 전체 행, 변경 후 값, 공시 ZIP 해시, 대조한 표의 셀, 배율, 인증 실행을 기록한다. 복구할 때는 이 기록과 현재 값을 먼저 대조하고 해당 자연키만 복원한다.

`tools/repair_financial_units.py`는 기본적으로 검증만 한다. `--apply`에서만 검증을 통과한 전체 계획을 한 트랜잭션으로 적용한다. 이미 정상화한 공시는 재적용하지 않으며, 확인되지 않은 금액이나 동시 변경이 있으면 중단한다.

## 환산 계약

USD CNY JPY HKD GBP 모두 FMP의 직접 KRW 통화쌍을 사용한다. 환율 단위는 외화 1단위당 원이다. 특히 JPYKRW는 100엔당 원이 아니다. KRW 자체의 환율은 1이다.

Gold의 신호일보다 날짜가 작은 가장 최근 평일 FX 종가만 사용한다. 같은 날짜의 글로벌 FX 종가를 국내 장 마감 때 사용하지 않는다. 7일보다 오래된 환율, 지원하지 않는 통화, 누락된 환율은 결측이며 1로 대체하지 않는다. API의 주말 재개장 관측은 사용하지 않는다. 이는 환율 가격의 과거 날짜 기준이며 당시 수집한 데이터 빈티지를 보장한다는 뜻은 아니다.

각 신호 시점에서 재무 금액을 같은 시점의 환율로 KRW로 환산한다. 외화 종목은 공시일뿐 아니라 거래일마다 재무 상태를 다시 계산한다. 같은 통화의 분기 합계와 FY 차감에는 같은 환율이 적용된다. 변환값이 누락된 분기를 제외하고 불완전한 TTM을 합산하지 않는다. 미래 환율 역방향 채우기는 하지 않는다.

`pipeline/silver/fx_rates.py`는 원본 응답과 해시를 보존하고, 통화쌍, 날짜, 양수 유한값, OHLC 관계, 장기간 누락을 검사한다. 기존 날짜의 환율 값이 달라지면 자동 덮어쓰기 대신 검토를 요구한다. 일일 파이프라인에도 최근 7일 수집을 연결했지만 이 코드의 운영 배포는 별도다.

## 검증 결과

수정 SQL 전체를 RDS의 임시 테이블에서 실행한 대표 사례다. 표의 수정값은 검증 계산 결과이며 아직 기존 Gold 물리 테이블을 덮어쓴 값은 아니다.

| 종목과 날짜 | 팩터 | 기존 Gold 값 | 수정 계산값 |
| --- | --- | ---: | ---: |
| 아남전자 2022년 8월 31일 | adv20_to_book_equity | 132.609727 | 0.098215 |
| 코오롱티슈진 2022년 10월 31일 | adv20_to_book_equity | 1120.174087 | 0.788533 |
| 네오이뮨텍 2023년 5월 31일 | shares_to_capital_stock | 49988.601416 | 37.956994 |
| 소노스퀘어 2025년 1월 31일 | asset_to_market | 1233421.954349 | 1.233422 |

수정 후 소노스퀘어 해당 연결 자산은 159266074177원, SK네트웍스 해당 연결 자산은 7814615000000원이다. available_date와 원래 공시 시점은 변경하지 않았다. 기본 단위 테스트 외에 전체 테스트 1141개가 통과했다.

## 후속 운영 작업

43개 공유 계산 팩터는 2018년 3월 2일부터, market_leverage와 paid_in_capital_ratio는 2015년 6월 25일부터, operating_return_on_capital_employed는 2017년 2월 27일부터 2026년 9월 30일까지 재생성한다. 외화 환산과 오류 공시는 성장률 및 과거 변화량에도 영향을 주므로 문제 날짜 하나만 수정해서는 안 된다. 변경된 값으로 해당 거래일의 전체 종목 순위도 다시 계산한다. 재무를 사용하지 않는 독립 가격 팩터 3개는 기존 승인 버전을 유지한다.

새 버전의 전체 범위와 결측 및 중복을 확인한 뒤 승인 전환하고, 그 후 전략 입력 캐시를 새 Gold 버전으로 재구축한다. 전략과 대시보드 갱신은 별도 실행이다. 수익률 개선 여부는 아직 측정하지 않았으며 데이터 수정을 성과 개선으로 단정하지 않는다.
